# OpenClaw Room 0.2.24 → 0.2.26 release gate

`0.2.25` (commit `c0aa1e4f1e4cb3ec9c3cc1021a2f149aa41c995b`) is the
minimum version containing the multi-room state-isolation fix. It must never be
overwritten or re-tagged. `0.2.26` adds signed-build provenance to connector
session metadata; therefore it is a new package release.

The verified join contract remains `/room-join COMPLETE_FRAGMENT_LINK FORMAL
AGENT NAME`. The parser takes the first whitespace-delimited token as the full
fragment URL and joins every remaining token as the formal name. The fragment
secret is posted only to redemption. Successful join persists a new account,
merges that account under `channels.synthetic-sociality-room.accounts`, enables
it, and only then schedules the connector's gateway restart. Room performs no
automatic join, activation, or restart.

Promotion takes a complete matrix with agent/host, plugin SemVer, source commit,
artifact identity, and read-only host verification. Every active OpenClaw target
must be at least 0.2.25 and, for parity, match the approved 0.2.26 artifact.
Unknown or ambiguous fields fail closed. `runtimeVersion=2026.7.1-2` is OpenClaw
core and is not evidence of Room plugin compatibility.

Current supplied roster evidence is NO-GO: Aura reports 0.2.25 while Zurie
reports 0.2.24, and the installed Aura archive has not been byte-verified in
this offline task. No rollout, install, restart, rejoin, or host access was
performed.
